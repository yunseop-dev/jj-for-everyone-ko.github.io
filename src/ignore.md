````admonish reset title="진행 상황 초기화" collapsible=true
```sh
````

Bob의 작업 상황을 확인해 봅시다.

```sh
cd ~/jj-tutorial/repo-bob
```

과제를 맡은 부분을 마친 그는 제출물을 고민하고 있습니다.
선생님은 `submission_alice_bob.tar.gz`라는 tarball을 받길 원합니다.
몇 번의 [시행착오](https://xkcd.com/1168/) 끝에 tarball을 만드는 명령을 찾아냈습니다.

```sh
tar czf submission_alice_bob.tar.gz README.md
```

(직접 실행해 보세요!)

만약 Alice가 최종 제출을 맡게 된다면 이런 과정을 다시 반복하지 않도록 돕고 싶습니다.
그래서 문서에 명령을 추가하기로 합니다.

```sh
echo "
## Submission

Run the following command to create the submission tarball:

~~~sh
tar czf submission_alice_bob.tar.gz [FILE...]
~~~" >> README.md
```

Bob은 Alice와 공유하는 원격에 항상 깨끗한 커밋만 푸시합니다.
(Bob처럼 하세요!)

이런!
Bob의 연구 결과물도 커밋에 포함된 것 같습니다.
`submission_alice_bob.tar.gz` tarball은 버전 관리 대상이 아닙니다.

기본적으로 Jujutsu는 프로젝트의 모든 파일을 워킹 카피에 기록합니다.
대체로 원하는 행동이지만, 때로는 특정 파일을 무시하도록 Jujutsu에 알려야 합니다.
이를 위해 프로젝트에 `.gitignore` 파일이 있으면 읽어서 추적하지 말아야 할 파일 이름·디렉터리·패턴 목록으로 삼습니다.

문제를 해결하기 위해 Bob은 tarball을 대상으로 하는 패턴을 `.gitignore`에 추가합니다.

```sh
echo "*.tar.gz" > .gitignore
```

별표 `*` 는 어떤 파일 이름과도 일치할 수 있는 특별한 [glob](https://en.wikipedia.org/wiki/Glob_(programming)) 문자입니다.
따라서 `submission_alice_bob`을 포함한 모든 파일과 매칭됩니다.
정확한 파일명 `submission_alice_bob.tar.gz`만 `.gitignore`에 추가해도 되지만, 위 패턴을 쓰면 _모든_ tarball을 아울러 처리할 수 있습니다.

````admonish info title="전역적으로 파일 무시하기" collapsible=true
개인 용도로만 사용하는 파일이 여러 프로젝트에 공통으로 존재할 때가 있습니다.
그럴 땐 특정 프로젝트가 아니라 전역적으로 무시 목록에 추가하는 것이 합리적입니다.
작업하는 모든 프로젝트의 `.gitignore`에 일일이 적어 넣는 것은 귀찮으니까요.

macOS 사용자에게 해당되는 예가 있습니다.
Finder 앱은 열어 본 디렉터리에 `.DS_Store`라는 숨김 파일을 남깁니다.
이 파일은 아무 곳에나 생길 수 있으며, 버전 관리에 포함될 일은 거의 없습니다.
macOS를 사용한다면 전역 `.gitignore`에 `.DS_Store`를 추가해 보세요.

```sh
echo ".DS_Store" >> ~/.gitignore
```
````

음... `.gitignore` 파일은 추가됐지만 tarball이 여전히 커밋에 포함돼 있습니다.
Jujutsu는 이미 추적 중인 파일에 대해서는 `.gitignore`를 적용하지 않기 때문입니다.
원치 않는 파일이 추적된 뒤에 `.gitignore`를 추가했으니 효과가 없었던 것이죠.
다행히 Jujutsu에는 이미 추적 중인 파일을 추적 대상에서 제외하는 명령이 있습니다.

```sh
jj file untrack submission_alice_bob.tar.gz
```

`untrack` 명령은 해당 파일이 `.gitignore`에 등록되어 있을 때만 동작합니다.
그렇지 않으면 추적을 해제하자마자 곧바로 다시 추적하기 때문입니다.
디렉터리 전체를 무시하거나 추적 해제할 수도 있습니다.

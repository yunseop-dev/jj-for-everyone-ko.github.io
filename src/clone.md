# 원격 복제

````admonish reset title="진행 상황 초기화" collapsible=true
이 장의 시작으로 되돌리려면 다음 명령을 실행하세요.

```sh
curl https://jj-for-everyone.github.io/reset.sh | bash -s clone
cd ~/jj-tutorial/repo
```
````

튜토리얼을 시작할 때는 `jj git init`으로 완전히 새로운 프로젝트를 만들었습니다.
이후에 백업을 위해 원격을 추가했죠.
현실에서는 정반대인 경우가 많습니다.
이미 존재하는 저장소에서 작업해야 합니다.

그 상황을 시뮬레이션하기 위해 주 저장소를 삭제해 봅시다.

```sh
cd ~
rm -rf ~/jj-tutorial/repo
```

이제 원격 저장소만 남았습니다.
어떻게 해야 "로컬" 사본을 다시 만들어 계속 작업할 수 있을까요?
저장소의 사본을 얻는 과정을 **클론(clone)** 한다고 부릅니다.
관련 Jujutsu 명령도 같은 이름입니다.

```sh
jj git clone ~/jj-tutorial/remote ~/jj-tutorial/repo
```

마지막 두 인자는 (1) 복제의 **원본** 과 (2) 복제한 저장소를 저장할 **대상** 입니다.
원격에서 클론하면 기본 이름 `origin`으로 자동 연결됩니다.

튜토리얼을 위해 저장소 전용 작성자 설정도 다시 만들어야 합니다.

```sh
cd ~/jj-tutorial/repo
jj config set --repo user.name "Alice"
jj config set --repo user.email "alice@local"
jj metaedit --update-author
```

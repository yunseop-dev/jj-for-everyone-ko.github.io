작업을 개별 커밋으로 분리하고 싶다면 어떻게 해야 할까요?

## 특정 파일만 커밋하기

첫 번째 방법은 워킹 카피에서 **특정 파일만** 커밋하는 것입니다.
작업 1은 전용 파일에 있으니 이 방법이 통합니다.
커밋할 파일 이름을 `jj commit`에 인자로 넘기면 됩니다.

```sh
jj commit --message "Implement task 1" task_1.txt
```

생성된 커밋은 `jj show @-`로 확인해 봅시다.

이처럼 하나의 파일을 여러 커밋으로 나누려면 더 강력한 도구가 필요합니다.

## 파일 일부만 커밋하기

`jj commit`에는 `--interactive` 플래그가 있습니다.
이 플래그를 사용하면 터미널 사용자 인터페이스(TUI)가 열립니다.
터미널을 차지하고 텍스트 기반 GUI를 띄우는 방식입니다.
모든 사용자에게 직관적이지 않을 수 있으니 천천히 살펴보겠습니다.

```sh
jj commit --interactive
```

다음과 비슷한 화면이 나올 것입니다.

![](./scm_record_1.png)

먼저 메뉴 바를 살펴보세요.
터미널이지만 클릭할 수 있습니다!
`[File]`을 클릭하면 `[Confirm]`, `[Quit]` 항목이 있는 드롭다운이 열리고, 단축키 <kbd>c</kbd>, <kbd>q</kbd>도 표시됩니다.
다른 메뉴들도 직접 탐색해 보세요.

메뉴 바 아래에는 워킹 카피의 변경 사항이 표시됩니다.
현재는 변경된 파일 이름만 보입니다.
오른쪽 화살표를 눌러 파일 "안"으로 들어가면 내용이 보입니다.

![](./scm_record_2.png)

들여쓰기는 계층을 나타냅니다.
파일 → 연속된 변경 줄(섹션) → 개별 줄 순입니다.

이제 첫 번째로 커밋할 줄을 선택합니다.
이번에는 작업 2 줄입니다.
화살표로 해당 줄로 이동 후 <kbd>Space</kbd>로 선택합니다.

![](./scm_record_3.png)

원하는 줄만 선택했다면 <kbd>c</kbd>(또는 메뉴에서 File > Confirm)를 눌러 확정합니다.
TUI가 닫히고 커밋 메시지를 입력할 편집기가 열립니다.
"Implement task 2"를 입력한 뒤 저장/종료하세요.
`jj show @-`, `jj show`로 파일이 두 커밋으로 잘 나뉘었는지 확인할 수 있습니다.

마지막으로 작업 3을 커밋하고, 세 커밋을 원격으로 푸시하며 정리합시다.

```sh
jj commit --message "Implement task 3"
jj bookmark move main --to @-
jj git push
```

```admonish success title="레벨 3 완주! 🎉"
이제 버전 관리 중 겪을 수 있는 대부분의 문제를 스스로 해결할 수 있습니다.
배운 내용을 정리해 볼까요?
- `jj undo`는 저장소 전체 상태를 한 단계씩 되돌립니다. 실수해도 괜찮으니 마음껏 실험하세요.
- 새로 클론한 뒤 원격에만 있는 북마크로 작업하려면 `jj bookmark track`을 실행하세요.
- 두 브랜치를 합칠 때 같은 부분을 수정했다면 충돌이 발생합니다. 충돌 표식을 정리해 의미 있는 결과를 만들어야 합니다.
- 더 이상 필요 없는 커밋은 `jj abandon`으로 삭제할 수 있습니다.
- `jj restore`로 파일 내용을 복원할 수 있습니다. 기본은 부모 커밋이지만 `--from`으로 다른 커밋을 지정할 수 있습니다.
- 워킹 카피에 섞여 있는 변경은 `jj commit --interactive`로 나눠서 커밋할 수 있습니다.

이제 필요한 거의 모든 지식을 갖췄습니다.
대부분 상황에서 막히지 않고 생산적으로 일할 수 있을 겁니다.
여기서 멈추기로 해도 괜찮습니다.
```

# 모두를 위한 Jujutsu

Git이나 다른 버전 관리 시스템 경험이 전혀 없어도 따라 할 수 있는 Jujutsu 튜토리얼입니다.

[mdBook](https://github.com/rust-lang/mdBook)으로 렌더링하며 [jj-for-everyone.github.io](https://jj-for-everyone.github.io)에서 볼 수 있습니다.

## 기여하기

오탈자 같은 작은 수정은 언제든 PR로 보내 주세요.
큰 규모의 콘텐츠 제안은 [이슈](https://github.com/jj-for-everyone/jj-for-everyone.github.io/issues/new)를 열어 주시면 감사하겠습니다.
경험담도 정말 듣고 싶습니다. 예를 들어 이런 질문에 답해 주실 수 있습니다.
- 튜토리얼로는 해결되지 않은 Jujutsu 관련 답답함이 있었나요?
- 설명이 충분히 명확하지 않은 구간이 있었나요?
  (무언가 이해되지 않았다면, 아마 튜토리얼 탓일 겁니다!)
- 어떤 레벨을 끝냈는데, 레벨 개요에서 약속한 능력을 갖추지 못한 느낌이었나요?
- 꼭 다뤄야 할데 빠진 내용이 있나요?
- 콘텐츠 구성이 더 나아질 여지가 있다고 느끼나요?

튜토리얼을 더 나은 방향으로 발전시키는 데 도움을 주셔서 감사합니다!
